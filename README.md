# Telegram Music Bot (সহজ ফোল্ডার কাঠামো)

সব ফাইল একই ফোল্ডারে আছে—কোনো সাবফোল্ডার নেই। তাই GitHub অ্যাপ দিয়ে ফাইল আপলোড করা সহজ।

## ফাইল পরিচিতি
- `config.py` — পরিবেশ ভেরিয়েবল সেটিংস
- `clients.py` — বট, অ্যাসিস্ট্যান্ট, PyTgCalls ও MongoDB সেটআপ
- `db.py` — ব্রডকাস্টের জন্য ব্যবহারকারী ও গ্রুপের তথ্য সংরক্ষণ
- `helpers.py` — টেক্সট স্টাইল ও প্রসেসিং ইমোজি
- `music_queue.py` — প্রতিটি চ্যাটের গান-কিউ ও চলমান গানের তথ্য
- `nowplaying.py` — থাম্বনেইল থেকে “এখন চলছে” কার্ড তৈরি
- `youtube.py` — YouTube সার্চ ও স্ট্রিম URL
- `play.py` — কমান্ড ও বোতাম পরিচালনা
- `app.py` — বট চালু করার মূল ফাইল
- `generate_session.py` — অ্যাসিস্ট্যান্টের `STRING_SESSION` তৈরি
- `requirements.txt`, `Dockerfile`, `sample.env` — নির্ভরতা, ডিপ্লয় ও নমুনা কনফিগারেশন

## সেটআপ
1. **প্রয়োজনীয় তথ্য সংগ্রহ করুন:** `API_ID` ও `API_HASH` নিন `my.telegram.org` থেকে, `BOT_TOKEN` নিন Telegram-এর `@BotFather` থেকে, এবং `MONGO_DB_URI` তৈরি করুন MongoDB Atlas-এ। `OWNER_ID` পেতে `@userinfobot` ব্যবহার করতে পারেন।
2. **`STRING_SESSION` তৈরি করুন:** `python generate_session.py` চালান। এর জন্য আলাদা Telegram অ্যাকাউন্ট ব্যবহার করুন। সেশন স্ট্রিং কাউকে দেবেন না।
3. **`sample.env` কনফিগার করুন:** ফাইলটির কপি `.env` নামে তৈরি করে নিজের ভেরিয়েবলগুলো পূরণ করুন। `SUPPORT_URL` ও `CHANNEL_URL`-এ নিজের সাপোর্ট গ্রুপ ও আপডেট চ্যানেলের লিংক দিন।
4. **GitHub-এ আপলোড:** সব কোড ফাইল রিপোজিটরির মূল ফোল্ডারে রাখুন। আসল `.env` ফাইল বা গোপন টোকেন GitHub-এ আপলোড করবেন না।
5. **Render-এ ডিপ্লয়:** `New +` → `Web Service` → `Docker` বেছে নিয়ে Environment অংশে প্রয়োজনীয় ভেরিয়েবল দিন, তারপর Deploy করুন। `RENDER_EXTERNAL_URL` সাধারণত Render নিজে সেট করে।
6. **গ্রুপে সেটআপ:** বট ও অ্যাসিস্ট্যান্ট—দুটোকেই গ্রুপে যোগ করুন, ভয়েস চ্যাট চালু করুন, তারপর `/play <song>` দিয়ে পরীক্ষা করুন।

## কমান্ড
- `/play <song>` — গান চালান অথবা কিউতে যোগ করুন
- `/skip` — পরের গান চালান
- `/pause` / `/resume` — বিরতি দিন / আবার চালু করুন
- `/stop` — গান বন্ধ করে ভয়েস চ্যাট ছাড়ুন এবং কিউ খালি করুন
- `/id` — আপনার ও গ্রুপের আইডি দেখুন
- `/reload` — বট অ্যাডমিন কি না পরীক্ষা করুন
- `/broadcast <msg>` — সব ব্যবহারকারীকে বার্তা পাঠান (শুধু `OWNER_ID`)
- `/addvd` — ব্যক্তিগত `/start` বার্তার জন্য ছবি/ভিডিও/GIF সেট করুন (শুধু `OWNER_ID`)
- `/delvd` — ব্যক্তিগত `/start` বার্তার মিডিয়া সরান (শুধু `OWNER_ID`)
- `/addvd2` / `/delvd2` — গ্রুপের `/start` বার্তার মিডিয়া সেট/সরান (শুধু `OWNER_ID`)

## গুরুত্বপূর্ণ
`/skip`, `/pause`, `/resume` ও `/stop` শুধু গ্রুপ অ্যাডমিন, বটের মালিক অথবা বর্তমান গান অনুরোধকারী ব্যবহার করতে পারবেন। সাধারণ ব্যবহারকারী `/play` ব্যবহার করতে পারবেন।

## “Peer id invalid” সমস্যার নোট
অ্যাসিস্ট্যান্টের Pyrogram সেশনে কোনো গ্রুপের peer/access_hash ক্যাশ না থাকলে এই সমস্যা দেখা দিতে পারে। `app.py` চালুর সময় ডায়ালগগুলো ক্যাশ করার চেষ্টা করে; তবুও সমস্যা হলে `play.py` ডায়ালগ রিফ্রেশ করে আবার চেষ্টা করে।
